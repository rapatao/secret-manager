# Security policy

## Reporting a vulnerability

Do not open a public issue for security problems. Report them privately through GitHub:
[Report a vulnerability](https://github.com/rapatao/secret-manager/security/advisories/new).

Include the version, how to reproduce the issue and its impact. You will get an answer as soon as possible, and the fix is released before the advisory is published.

## Supported versions

Only the latest release gets security fixes.
